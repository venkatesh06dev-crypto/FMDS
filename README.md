# FMDS
# Fake Medicine Detection System
**Theme:** Dark hacker scanner | **Domain:** Healthcare

## Features
- Enter barcode/QR code → registry lookup
- Verified database with 5 registered medicines
- Shows: manufacturer, batch number, expiry, license
- Blockchain-style hash verification
- Color-coded result: GENUINE / FAKE / SUSPICIOUS
- Demo codes provided in sidebar

## Run
```bash
streamlit run app.py
```

## Demo Codes
- MED-2024-001 (Genuine Paracetamol)
- FAKE-001 (Fake Medicine)
- UNKNOWN-XYZ (Unknown)
